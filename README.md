# 📚 Learning Catalog

A collection of focused learning projects built while exploring backend development, distributed systems, and modern software engineering concepts.

Each project is intentionally small and concentrates on understanding one technology or concept in depth rather than building a complete production application.

---

## 🎯 Purpose

This repository serves as my personal learning workspace where I experiment with new technologies, understand how they work internally, and practice implementing them through hands-on projects.

The goal is to build a strong foundation before using these technologies in larger production-ready applications.

## 📌 Learning Approach

Each project focuses on:

* Understanding core concepts
* Building from scratch
* Following clean architecture where appropriate
* Learning industry best practices
* Documenting important takeaways

These are learning projects, not complete production applications. Larger portfolio projects are maintained in their own dedicated repositories.
